# 오픈마켓 주문 수집기

네이버 스마트스토어(추후 쿠팡, 지마켓 추가 예정) 주문을 한 화면에서 모아보는 웹 서비스입니다.
코딩을 처음 접하는 분도 따라 할 수 있도록 설치부터 실제 연동까지 순서대로 안내합니다.

## 이 프로그램이 하는 일

- 마켓별로 "지금 수집" 버튼을 누르면 새 주문을 가져와 DB에 저장합니다.
- 대시보드에서 마켓/상태/검색어로 주문을 걸러볼 수 있습니다.
- 아직 마켓 API 키가 없어도 **테스트 모드**로 가짜 주문을 만들어 화면과 흐름을 먼저 체험할 수 있습니다.
- 설정 화면에서 네이버 Client ID/Secret을 입력하고 테스트 모드를 끄면 실제 주문을 수집합니다.
- 쿠팡, 지마켓은 같은 구조(`collectors/` 폴더)로 나중에 쉽게 추가할 수 있게 만들어져 있습니다.

## 1. 준비물: Python 설치

- [python.org](https://www.python.org/downloads/) 에서 Python 3.11 이상을 설치하세요.
- 설치 중 "Add Python to PATH" 체크박스를 꼭 체크하세요 (Windows).
- 설치 후 터미널(또는 명령 프롬프트)에서 확인:
  ```
  python3 --version
  ```

## 2. 설치 방법

```bash
cd 이_프로젝트_폴더

# 가상환경 만들기 (한 번만)
python3 -m venv venv

# 가상환경 켜기
source venv/bin/activate        # Windows는: venv\Scripts\activate

# 필요한 패키지 설치
pip install -r requirements.txt

# 환경설정 파일 만들기
cp .env.example .env
```

## 3. 실행 방법

```bash
source venv/bin/activate   # 이미 켜져 있다면 생략
python app.py
```

터미널에 `Running on http://127.0.0.1:5000` 이 보이면, 브라우저에서
**http://127.0.0.1:5000** 을 열어보세요.

종료는 터미널에서 `Ctrl + C`.

## 4. 처음 써보기 (테스트 모드)

기본적으로 모든 마켓은 "테스트 모드"가 켜져 있어서, API 키가 없어도 바로 체험할 수 있습니다.

1. 대시보드에서 "네이버 스마트스토어 지금 수집" 버튼 클릭
2. 가짜 주문이 몇 건 생성되어 표에 나타나는지 확인
3. 마켓/상태/검색어 필터도 눌러보기

## 5. 네이버 스마트스토어 실제 연동하기

1. [네이버 커머스API센터](https://apicenter.commerce.naver.com) 에 스마트스토어 판매자 계정으로 로그인
2. 애플리케이션 등록 후 **Client ID / Client Secret** 발급받기 (심사에 며칠 걸릴 수 있어요)
3. 이 프로그램의 **설정** 화면 접속
4. 네이버 카드에 Client ID / Client Secret 입력, "테스트 모드" 체크 해제 후 저장
5. 대시보드로 돌아가 "지금 수집" 클릭 → 실제 주문이 수집됩니다

> 네이버 오픈API는 정책/응답 형식이 바뀔 수 있습니다. 실제 연동 시
> `collectors/naver.py` 상단 주석의 공식 문서 링크에서 최신 스펙을 한 번
> 확인해 주세요. 만약 필드명이 달라 주문이 비어 보이면, 수집된 주문의
> `raw_json` (DB의 원본 응답)을 확인해 매핑을 맞추면 됩니다.

## 6. 쿠팡 / 지마켓은 언제 되나요?

지금은 테스트 모드(가짜 주문)만 지원합니다. 실제 연동을 원하시면:

- 쿠팡: WING 판매자센터에서 오픈API 키 발급 → `collectors/coupang.py` 새로 작성
- 지마켓/옥션: ESM+ 판매자센터에서 API 키 발급 → `collectors/gmarket.py` 새로 작성

두 경우 모두 `collectors/naver.py` 를 참고해서 같은 형태(`fetch_new_orders()`가
주문 딕셔너리 리스트를 반환)로 만들면, `app.py` 의 `/collect` 라우트에 분기 하나만
추가하면 바로 대시보드에 표시됩니다.

## 7. 자주 묻는 질문

**Q. API 키는 어디에 저장되나요?**
로컬 SQLite 파일(`orders.db`)에 저장됩니다. 이 프로그램을 외부 서버에 올려
여러 사람이 접속하게 하려면, 비밀번호 로그인 추가와 키 암호화 저장을
꼭 검토하세요. 지금 구조는 "내 컴퓨터에서 나 혼자 쓰는 것"을 기준으로
만들어졌습니다.

**Q. 주문이 중복 저장되지 않나요?**
`(마켓, 주문번호)` 조합이 이미 있으면 건너뛰므로, "지금 수집"을 여러 번
눌러도 같은 주문이 중복 저장되지 않습니다.

**Q. 자동으로 주기적 수집도 가능한가요?**
지금은 버튼을 눌러야 수집합니다. 익숙해지면 `APScheduler` 같은 라이브러리로
"5분마다 자동 수집"을 추가할 수 있어요 (필요하면 요청해주세요).

## 프로젝트 구조

```
app.py                 # 라우트(화면 연결)와 앱 실행
extensions.py           # DB 객체
models.py               # 주문(Order), 마켓 계정(MarketAccount) 테이블 정의
collectors/
  base.py               # 모든 수집기가 따라야 하는 공통 형태
  mock.py                # 테스트용 가짜 주문 생성기
  naver.py               # 네이버 커머스API 실제 연동
templates/               # 화면 (대시보드, 설정)
static/style.css         # 디자인
```
