## 네이버 API

키는 이 파일에 적지 않는다. 환경변수나 `.env`(git 제외)로 둔다.

| 용도 | API | 필요한 값 | 상태 |
| --- | --- | --- | --- |
| 국내 판매 여부·가격대 | 네이버 검색 API(쇼핑) `GET https://openapi.naver.com/v1/search/shop.json` | NAVER_CLIENT_ID, NAVER_CLIENT_SECRET (앱 이름 STL-CLOUD) | 발급 완료 |
| 12개월 검색 추이 | 데이터랩 검색어트렌드 `POST https://openapi.naver.com/v1/datalab/search` | 같은 키 (개발자센터 앱에 데이터랩 API 추가 필요) | 추가 여부 미확인 |
| 월간 검색량·경쟁도 | 검색광고 키워드도구 `GET https://api.searchad.naver.com/keywordstool` | SEARCHAD_API_KEY, SEARCHAD_SECRET, SEARCHAD_CUSTOMER_ID | 미발급 |

- 클라우드 세션에서는 openapi.naver.com 접속이 보안 정책으로 막혀(403) 실패했다. 로컬 Claude Code에서는 직접 호출이 될 가능성이 높으니 **먼저 curl로 직접 호출을 테스트**하고, 되면 Apps Script 중계는 필요 없다.
- 직접 호출이 안 되면 `naver_relay.gs`(Google Apps Script 웹앱 중계)를 배포해서 쓴다. 파일 상단 주석에 설정·배포 순서가 있다.
- Client Secret이 claude.ai 대화에 평문으로 노출됐다. 연결 확인 후 개발자센터에서 재발급할 것.
